# 1.1.2 — Özel isim etiketleri için ayrı tier satırı

1.1.1'de oyuncu sorgusu TAB'dan bağımsızdı, ancak çizim hâlâ normal Minecraft isim etiketini gerektiriyordu.
Bu sürüm, normal etiket boş/gizli olduğunda görünür oyuncunun üzerinde ayrı bir tier satırı çizer.
Sunucunun kendi hologramı değiştirilmez. Normal isimler önceki gibi tier ile tamamlanır.

- Ayrı satır yalnızca 64 bloktan yakın, görüş hattında, görünür ve yaşayan oyuncularda çizilir.
- Eğilmiş oyuncular, spectator, kendi oyuncun ve F1 ile gizlenen HUD hariçtir. Duvar arkası çizimi kapalıdır.
- `/utier fallback`: Ek özel etiket desteğini aç/kapat (varsayılan açık).
- `/utier debug [oyuncu]`: Sürüm, ayarlar, dünya/TAB durumu ve API sonucunu yerel sohbette gösterir.
- API hataları artık “kayıt yok” ile karıştırılmaz.
- Minecraft sunucusuna ek paket/komut göndermez; tier sorguları MCPvP'ye HTTPS üzerinden yapılır.

## Kurulum

Minecraft **26.2**, Java **25**, Fabric Loader **0.19.3+** ve 26.2 ile uyumlu Fabric API **0.153.0+26.2 veya üstü**.
Eski JAR'ı çıkar, `uebasusta123mcpvptieartagger-1.1.2.jar` dosyasını koy ve oyunu yeniden başlat.
`/utier debug` sürüm satırında `1.1.2` yazmalı. Önceki ayarlar korunur.

## Doğrulama ve sınır

Kaynaklar gerçek Minecraft 26.2 sınıflarına karşı derlendi; otomatik regresyon kontrolleri eklendi.
GitHub Release yalnızca tam Gradle derlemesi ve kontroller başarılı olursa yayımlanır.
DonutSMP'de canlı test yapılmadı. Sorun sürerse `/utier debug <oyuncu>` çıktısını ve oyuncunun
kafa üstünü gösteren ekran görüntüsünü paylaş. Sunucu özel hologram yüksekliği veya başka
bir modun çizimi iptal etmesi ek uyarlama gerektirebilir.
